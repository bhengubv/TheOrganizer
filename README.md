# TheOrganizer

TheOrganizer is one of four repos that work together:

| Repo | What it is |
|---|---|
| [TheOrganizer](https://github.com/bhengubv/TheOrganizer) (this repo) | File and folder manager |
| [TheProtector](https://github.com/bhengubv/TheProtector) | System protection |
| [TheEqualizer](https://github.com/bhengubv/TheEqualizer) | AI-driven network protection |
| [TheThreeAmigos](https://github.com/bhengubv/TheThreeAmigos) | The shared core the other three use |

TheOrganizer, TheProtector and TheEqualizer together are TheThreeAmigos.
